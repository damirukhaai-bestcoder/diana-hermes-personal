# Условия личного использования Diana Hermes Personal

Diana Hermes Personal предназначена для личного использования владельцем. Этот сайт описывает приложение; он не предлагает подписку, платную услугу или публичную регистрацию.

Владелец определяет поручения, подключённые аккаунты и допустимые действия. Запланированные личные сообщения выполняются только по явному запросу. Новый доступ, расходы и сообщения другим людям требуют соответствующего разрешения владельца.

ИИ может ошибаться. Важные даты, адресатов, суммы и документы следует проверять перед действиями с последствиями. Помощник не должен сообщать об успешной записи в Google без подтверждения API и последующего чтения результата.

Владелец может прекратить использование и отозвать Google-доступ. Работа зависит от доступности сервера и подключённых сервисов; непрерывная доступность не гарантируется. Условия и ограничения Google, Telegram, хостинга и выбранного ИИ-провайдера действуют для соответствующих сервисов.
