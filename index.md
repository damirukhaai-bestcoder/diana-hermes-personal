# Diana Hermes Personal

Diana Hermes Personal — личный ИИ-помощник владельца приложения. По его поручению Диана помогает вести задачи и календарь, работать с документами и таблицами и находить сведения в контактах выбранного Google-аккаунта.

Google-доступ выдаётся через отдельное согласие владельца аккаунта. Приложение может работать с событиями Calendar и задачами Tasks, создавать и изменять только созданные или явно выбранные для приложения файлы Drive, Docs и Sheets, а также читать контакты. Изменение контактов не запрашивается. Эта конфигурация не запрашивает Gmail или Google Maps.

Приложение предназначено для личного использования владельцем. Публичная страница описывает помощника и не предоставляет доступ к нему или его данным.

Обзор дня выполняется по запросу. Личные сообщения по расписанию создаются только после явного поручения с темой и временем. Для записи задачи или события Диана проверяет результат обращения к соответствующему Google API.
